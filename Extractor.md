# CORE RULE: DO NOT HALLUCINATE

Separate everything you write into one of these implicit confidence levels:

### OBSERVED

Directly visible in the footage.

### STRONGLY INFERRED

Not perfectly measurable, but strongly supported by visible evidence.

### SPECULATIVE

A plausible interpretation but impossible to establish confidently from the video alone.

Do not present speculation as fact.

When uncertain, use language such as:

- “appears to be”
    
- “likely”
    
- “approximately”
    
- “visually resembles”
    
- “cannot be confirmed from the available frames”
    
- “the footage suggests”
    

It is better to explicitly record uncertainty than to invent details.

- percentage of frame
    
- focal-length ranges
    
- camera height
    
- color HEX
    
- light direction
    
- horizon position
    
- shot duration
    
- relative object scale
    

Mark estimates as approximate.

Never manufacture precision.

---

### RECORD ABSENCE

What is missing can define style as strongly as what is present.

Examples:

- no saturated foliage
    
- no perfectly clean clothing
    
- no pure white light
    
- no dense architecture
    
- no heavy lens flare
    

---

### DISTINGUISH DESIGN FROM STORY

The document is a visual reference bible.

Story information should only be mentioned when necessary to explain visual design.

---

### DO NOT OPTIMIZE FOR BREVITY

The goal is completeness.

If something is visually meaningful, record it.

Repeated visual evidence should be consolidated into rules, but unique details should not be discarded merely to shorten the document.

# MOST IMPORTANT FINAL INSTRUCTION

**Do not create a generic film-analysis document.**

The final `INSIPRATION-DESIGN.md` must contain enough concrete visual evidence that it could serve as the **single source of truth for recreating the visual universe of this particular video**.

The document should allow us to later say:

> “Create a completely new scene using the visual language defined in `INSIPRATION-DESIGN.md`.”

and obtain something that feels visually continuous with the original footage.

Capture the **visual grammar**, not merely the objects.

Capture:

**what exists → how it looks → how it relates to everything else → how consistently it appears → why it creates this particular visual identity → how to reproduce it.**

Perform multiple inspection passes before finalizing.

Prioritize observable evidence over assumptions.

When in doubt, inspect again.
