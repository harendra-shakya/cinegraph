## Track 2 requirement

Track 2 requires Livepeer Agent and OriginTrail DKG to work together so that verifiable knowledge materially improves the application. The submission must use an actual DKG Edge Node or DKG network integration to create, retrieve, query, or verify a Knowledge Asset; explain what it contains and why; show how it changes application behavior or value; use minimized, consented, non-sensitive data; and state what is local, shared, or published.

Testnet publication is preferred because it makes network verification easier, but it is not mandatory. An Edge Node-only path qualifies when the working create/read/query path is demonstrated and documented. A UAL is required only when an asset is published to a DKG network.

## Judging scoreboard

The participant pack names these decision criteria:

1. Usefulness and originality.
2. Clarity of user and purpose.
3. Meaningful use of Livepeer Agent.
4. Convincing end-to-end execution.
5. Product judgment around scope, interaction, and reliability.
6. Potential to continue as an open-source project, tool, or business.
7. For Track 2 specifically, whether verifiable knowledge materially improves the application.

The pack does not publish a numeric weighting scheme. We therefore treat these as the external scoreboard and avoid inventing a percentage score for the judges.

## Evidence obligations for OpenCinema

The demo must make the causal chain visible:

`Try 1 artifact -> independent evaluation -> structured lesson -> DKG write/read -> lesson shown before Try 2 -> changed Try 2 direction -> Try 2 artifact`

The defensible claim is that Try 2 used named retrieved knowledge. A higher model-judge score alone is not proof that DKG caused an improvement.

## Submission safety

Do not put API keys, wallet material, personal information, restricted media, confidential prompts, private machine paths, large media bytes, or sensitive logs in the public repository, screenshots, or Knowledge Assets. Use owned or permissioned test media and document third-party assets.
